# ANALISIS TREN ANGKA HARAPAN HIDUP (AHH) DI INDONESIA

## A. Raw Data
Dataset berupa file csv yang berisi kumpulan angka harapan hidup penduduk Indonesia berdasarkan provinsi pada rentang waktu 2010-2024. Seluruh dataset digabung dengan menyamakan nama kolom menjadi Kabupaten_Provinsi, Jenis Kelamin, Nilai, Tahun, Sumber.

## B. Tujuan
Mengolah, membersihkan, dan menganalisis data Angka Harapan Hidup (AHH) di Indonesia dari berbagai sumber data.

## C. Output
Berikut hasil pengolahan data yang dapat dianalisis lebih lanjut.
  1.  Tren AHH Nasional
  2.  Perbandingan AHH berdasarkan jenis kelamin
  3.  Tren AHH Laki-laki VS Perempuan
  4.  Faktor yang mempengaruhi AHH
  5.  Pola khusus AHH per wilayah
